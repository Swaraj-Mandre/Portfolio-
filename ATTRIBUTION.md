# Source and attribution

Local adaptation for Swaraj Mandre of Ali Bagheri's Dennis Snellenberg portfolio recreation.

- Repository: https://github.com/AliBagheri2079/dennis-snellenberg-portfolio
- Original portfolio design reference: https://dennissnellenberg.com/
- Light-control interaction reference: https://www.seanhalpin.xyz/
- Paper hero composition and animation reference: Raagav Sundar, Graphic Design Portfolio 2026, https://www.behance.net/gallery/252076827/GRAPHIC-DESIGN-PORTFOLIO-2026

The cloned repository contained no LICENSE file. Its README describes the code as open source and invites exploration and reuse. Original source history and README attribution are retained. This local adaptation does not claim authorship of the original design, interactions, or bundled typeface. Check reuse permissions before public release.

Swaraj's project content and selected local evidence assets replace the reference portfolio's identity and Cloudinary media. The 24-step light control is a new implementation inspired by Sean Halpin's interaction.

The paper hero is a new implementation of the referenced composition using Swaraj's personalised illustrated portrait, generated paper texture, custom SVG handwriting and CSS eye animation. It does not include the reference creator's portrait or source code.
